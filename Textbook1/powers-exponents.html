    Section 1.2 Powers, Exponents

    A stand alone expression of the form \(w^{r}\) is called a power. The \(w\) is the base and the \(r\) is the exponent. The basic meaning of \(w^{r}\) is that there are \(r\) factors of \(w\text{,}\) in other words, the exponent counts the number of factors. This is easy to see for a positive whole number exponent: \(w^{5}=w\cdot w\cdot w\cdot w\cdot w\text{.}\) What does it mean when the exponent is a negative number or maybe a fraction?
    🔗
    If we start with \(w^{5}=w\cdot w\cdot w\cdot w\cdot w\) we could add two more factors for a count of seven factors \(w^{7}=w^{5+2}\text{.}\) When we multiple in more factors we add to the exponent count. This gives us a basic exponent rule \(w^{n}w^{m}=w^{n+m}\text{.}\)
    🔗
    If we start with \(w^{5}=w\cdot w\cdot w\cdot w\cdot w\) we can remove factors by dividing, for instance we could remove 2 factors leaving 3 factors \(w^{3}=\frac{w^{5}}{w^{2}}\text{.}\) When we divide out factors, we subtract from the exponent count. This gives another basic exponent rule \(\frac{w^{n}}{w^{m}}=w^{n-m}\text{.}\)
    🔗
    What if we remove 5 factors from \(w^{5}\text{,}\) then the factor count would be zero. At the same time \(1=\frac{w^{5}}{w^{5}}\text{,}\) so \(w^{0}=1\text{.}\) We see that \(w^{0}=1\) for any base \(w\) except zero. We cannot use base zero because we cannot remove factors of zero by division.
    🔗
    What if we remove 7 factors from \(w^{5}\text{,}\) then the factor count would be \(-2\text{.}\) At the same time \(\frac{w^{5}}{w^{7}}=\frac{1}{w^{2}}\text{,}\) so \(w^{-2}=\frac{1}{w^{2}}\text{.}\) Another basic rule is \(w^{-n}=\frac{1}{w^{n}}\text{.}\) This rule allows us to covert positive exponent expression into negative exponent expression and visa versa. Note that there is no reason to prefer negative exponents over positive exponents, it is just a matter of context which type is more useful. In what follows we will not insist on positive exponent unless specifically stated.
    🔗
    At this point we have shown the meaning of the exponent counting factors when the exponent is a positive whole number, zero, and a negative whole number. Lets venture into exponents that are fractions. Consider \(w^{1/3}\text{,}\) the exponent should mean that by count there is one third of the factors; \(w^{1/3}w^{1/3}w^{1/3}=w\text{.}\) So \(w^{1/3}\) is the cube root of \(w\text{,}\) \(w^{1/3}=\sqrt[3]{w}\text{.}\) The general rule is \(w^{1/n}=\sqrt[n]{w}\text{.}\)
    🔗
    There is the basic exponent rule \(\left(w^{n}\right)^{m}=w^{nm}\text{.}\) To illustrate this, consider \(\left(w^{3}\right)^{2}=w^{3}w^{3}=w^{6}\text{,}\) the exponent counts 3 twice giving 6 factors. This allows us to use any fraction exponent, for example \(w^{3/5}=\left(w^{3}\right)^{1/5}=\sqrt[5]{w^{5}}\text{.}\)
    🔗
    One last basic exponent rule is for the power of a product of powers \(\left(w^{n}q^{r}\right)^{k}=w^{nk}q^{rk}\text{.}\) The left side of the rule says there are \(k\) factors of \(w^{n}q^{r}\text{,}\) but that would be \(k\) factors of \(w^{n}\) and \(k\) factors of \(q^{r}\text{.}\)
    🔗

    Subsection 1.2.1 Examples

    1. Convert the radical \(\sqrt[7]{t^{4}}\) into a power. \(\sqrt[7]{t^{4}}=\left(t^{4}\right)^{1/7}=t^{4/7}\)

      🔗
    2. Convert the expression \(w^{7}t^{-5}\) into an expression that only uses negative exponents. \(w^{7}t^{-5}=\frac{t^{-5}}{w^{-7}}\)

      🔗
    3. Convert the expression \(\frac{t^{6}t^{3}}{t^{12}}\) into a single power. \(\frac{t^{6}t^{3}}{t^{12}}=\frac{t^{9}}{t^{12}}=t^{-3}\)

      🔗
